## Overview

Amplitude Modulation (AM) is one of the fundamental techniques used in analog communication systems. In AM, the amplitude of a high-frequency carrier wave is varied in proportion to the message signal.

This project focuses on building a strong conceptual and practical understanding of AM through Python implementations and analysis. It is suitable for students, educators, and anyone learning communication systems.

---

## Key Objectives

- Explain the mathematical principles of AM.
- Demonstrate how a carrier signal is modulated by an information-bearing message.
- Visualize AM signals in the time domain.
- Analyze the frequency-domain behavior of modulated signals.
- Provide a clean and extensible Python codebase for experimentation.

---

## Features

- Signal generation for message and carrier waves.
- AM waveform construction and visualization.
- Frequency-domain inspection using spectrum analysis.
- Parameter control for frequency, amplitude, and modulation index.
- Educational structure designed for easy learning and modification.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.8 or later
- `pip`
- Recommended packages such as:
  - `numpy`
  - `matplotlib`
  - `scipy`

### Installation

Clone the repository:

```bash
git clone https://github.com/Mahmoudayesh145/Communication-project.git
cd Communication-project
```

Create and activate a virtual environment:

```bash
python -m venv venv
```

- On Windows:

```bash
venv\Scripts\activate
```

- On macOS/Linux:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

If a `requirements.txt` file is not present, install the libraries used by the project manually.

## Usage

Run the main Python file or notebook provided in the repository.

Examples:

```bash

```

or

```bash

```

If the project is notebook-based:

```bash

```

Then open the relevant notebook and execute the cells step by step.

> Update the command above to match the actual entry point of the repository.
